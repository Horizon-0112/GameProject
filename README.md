AIM BEAT — FPS 리듬게임 기획서
1. 게임 개요
항목	내용
게임 제목	AIM BEAT
장르	FPS / Rhythm / Action
개발 엔진	Unreal Engine 5.4.4
플랫폼	PC
플레이 방식	Single Player
시점	First Person
예상 플레이 시간	곡당 2~3분


한 줄 소개
음악에 맞춰 내려오는 노트를 정확한 타이밍에 조준하고 사격하여 점수를 획득하는 FPS 리듬게임

2. 게임 컨셉
플레이어는 1인칭 시점에서 총을 사용하여 음악에 맞춰 내려오는 노트를 맞힌다.
노트는 화면 앞의 여러 위치에서 내려오며, 플레이어는 노트가 판정선에 도달하는 순간 조준하여 사격해야 한다.
노트를 맞힌 타이밍에 따라 판정과 점수가 달라진다. 연속으로 노트를 맞히면 콤보가 증가하고, 노트를 놓치거나 잘못된 위치에 사격하면 콤보가 끊어진다.
곡이 끝나면 최종 점수, 최대 콤보, 정확도를 확인한다.
핵심 키워드
- Rhythm : 음악에 맞춘 사격
- Aim : 노트를 향한 정확한 조준
- Timing : 판정선에 도달하는 순간 사격
- Combo : 연속 명중으로 콤보 유지
3. 게임 목표
플레이어의 최종 목표는 다음과 같다.
1. 음악에 맞춰 내려오는 노트를 확인한다.
2. 노트의 위치에 조준점을 맞춘다.
3. 노트가 판정선에 도달할 때 사격한다.
4. 정확한 사격으로 점수와 콤보를 높인다.
5. 곡이 끝날 때까지 플레이한다.
6. 결과 화면에서 최종 기록을 확인하고 더 높은 점수에 도전한다.
4. Core Gameplay Loop
게임의 핵심 플레이 흐름은 다음과 같다.
1. 음악에 맞춰 노트가 등장한다.
2. 노트의 위치와 내려오는 속도를 확인한다.
3. 조준점을 노트에 맞춘다.
4. 판정선에 도달하는 순간 사격한다.
5. 명중 위치와 사격 타이밍에 따라 판정을 받는다.
6. 점수와 콤보가 갱신된다.
7. 다음 노트를 조준한다.
플레이어는 곡이 끝날 때까지 노트 확인 → 조준 → 사격 → 판정 → 다음 노트 조준의 과정을 반복한다.
5. 플레이어 조작
입력	기능
Mouse	시점 회전 및 조준
Left Click	총 발사
Esc	일시정지 / 메뉴 열기


플레이어는 고정된 위치에서 조준과 사격을 수행한다. 리듬 플레이에 집중할 수 있도록 이동과 재장전은 사용하지 않으며, 탄약은 무제한으로 설정한다.
6. 플레이어 기능
6.1 시점 및 조준
플레이어는 1인칭 시점에서 마우스로 화면을 회전하여 내려오는 노트를 조준한다.
주요 기능:
- 마우스에 따른 시점 회전
- 화면 중앙 조준점 표시
- 마우스 감도 설정
6.2 사격
플레이어는 마우스 왼쪽 버튼으로 총을 발사한다.
주요 기능:
- 클릭당 한 발 발사
- 조준점 방향으로 명중 여부 확인
- 총 발사 효과음 및 시각 효과
- 노트 명중 시 피격 효과
- 무제한 탄약
6.3 노트 및 타이밍 판정
노트는 음악에 맞춰 생성되어 판정선 방향으로 내려온다.
노트를 조준한 상태에서 사격해야 명중으로 인정되며, 사격 시점과 노트의 기준 시점 사이의 차이에 따라 판정이 결정된다.
판정	조건	결과
Perfect	기준 시점에 매우 가깝게 명중	높은 점수 / 콤보 증가
Good	허용된 시간 범위 안에서 명중	기본 점수 / 콤보 증가
Miss	노트를 놓치거나 잘못된 위치·타이밍에 사격	점수 없음 / 콤보 초기화


6.4 점수 및 콤보
플레이어는 정확하게 노트를 맞혀 점수를 획득한다.
주요 기능:
- 판정에 따른 점수 지급
- 연속 명중 시 콤보 증가
- Miss 발생 시 콤보 초기화
- 현재 점수와 콤보 표시
- 최대 콤보 기록
6.5 게임 진행 및 결과
음악이 시작되면 노트가 등장하고, 곡이 끝나면 결과 화면으로 이동한다.
결과 화면 표시 항목:
- 최종 점수
- 최대 콤보
- 정확도
- Perfect / Good / Miss 횟수
- 다시 플레이 / 메뉴로 돌아가기
정확도는 전체 노트 중 Perfect 또는 Good으로 맞힌 노트의 비율로 계산한다.
